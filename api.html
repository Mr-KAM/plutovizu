Référence API

Référence complète de toutes les fonctions et méthodes de plutovizu. Toutes les méthodes de Chart retournent self (sauf show() et get_figure()), ce qui permet le chaînage illimité.

Fonction de module

get_fonts(pattern, sort)

from plutovizu import get_fonts

get_fonts(pattern: str = None, sort: bool = True) -> List[str]

Retourne la liste des polices installées sur le système.

Paramètre Type Défaut Description
pattern str None Filtre par sous-chaîne (insensible à la casse)
sort bool True Trier alphabétiquement 
get_fonts()                   # toutes les polices
get_fonts(pattern='Times')    # polices contenant 'Times'

Thèmes

Voir la page Thèmes pour l’aperçu de chaque thème.

Fonction Rôle
set_theme(theme='editorial', context=None) Applique un thème à tous les graphiques suivants ; None revient au style matplotlib
theme_context(theme, context=None) Applique un thème seulement dans un bloc with
list_themes(source='all') Noms des thèmes : 'all', 'plutovizu', 'seaborn' ou 'morethemes'
get_theme(name) Copie des réglages d’un thème, pour en dériver un thème personnalisé
THEMES, SEABORN, MORETHEMES Dictionnaires nom → rcParams
DEFAULT_THEME 'editorial' : thème appliqué dès import plutovizu
CONTEXTS ('paper', 'notebook', 'talk', 'poster') : valeurs possibles de context
DESCRIPTIONS Dictionnaire nom → description 
from plutovizu import set_theme, theme_context, get_theme

set_theme('editorial')
with theme_context('wsj'):            # thème morethemes (paquet optionnel)
    Chart(df).line('x', 'y').show()
set_theme({**get_theme('pluto'), 'axes.titlesize': 20})

Classe Chart

__init__(data, figsize, theme)

Chart(data: pd.DataFrame, figsize: Tuple[float, float] = FIGSIZE,   # 16 × 10 cm
      theme: Optional[str] = None)
Paramètre Type Défaut Description
data pd.DataFrame — Jeu de données source
figsize Tuple[float, float] FIGSIZE (16 × 10 cm) Largeur × hauteur en pouces ; cm(largeur, hauteur) convertit des centimètres
theme str None Raccourci de set_theme(theme) — s’applique aussi aux graphiques suivants 
chart = Chart(df)
chart = Chart(df, figsize=(14, 8), theme='pluto')

Graphiques

line

.line(x: str, y: Union[str, List[str]],
      marker: str = 'o', linewidth: float = 2,
      markersize: float = 6, alpha: float = 1.0) -> Chart

Courbe simple ou multi-séries. Plusieurs colonnes y tracent une ligne par colonne.

chart.line('date', 'ventes')
chart.line('date', ['ventes', 'coûts', 'profit'], marker='s', linewidth=1.5)

bar

.bar(x: str, y: str | List[str], horizontal: bool = False,
     width: float = 0.8, alpha: float = 0.8, color: str = None,
     stacked: bool = False, show_values: bool = False,
     value_format: str = '{:,.0f}') -> Chart

Barres verticales ou horizontales. Plusieurs colonnes y : barres groupées, ou empilées avec stacked=True. show_values=True écrit les valeurs sur les barres.

chart.bar('region', 'ca', show_values=True)
chart.bar('categorie', 'valeur', horizontal=True, color='steelblue')
chart.bar('annee', ['riz', 'mais', 'mil'], stacked=True)

scatter

.scatter(x: str, y: str, size: Union[str, float] = 50,
         color: Optional[str] = None, alpha: float = 0.7,
         marker: str = 'o') -> Chart

Nuage de points. size et color acceptent un nom de colonne (encodage) ou une valeur fixe.

chart.scatter('temp', 'ventes', size='population', alpha=0.6)

histogram

.histogram(column: str, bins: Union[int, str] = 30,
           alpha: float = 0.7, color: str = None,
           density: bool = False, edgecolor: Optional[str] = None) -> Chart
Paramètre Défaut Description
bins 30 Nombre de classes ou stratégie ('auto', 'fd', 'scott'…)
density False Normaliser pour que l’aire totale vaille 1 
chart.histogram('salaire', bins=50, density=True, color='steelblue')

boxplot

.boxplot(columns: Union[str, List[str]],
         vert: bool = True, patch_artist: bool = True) -> Chart

Boîte à moustaches — médiane, IQR et valeurs aberrantes.

chart.boxplot(['maths', 'français', 'sciences'])
chart.boxplot('note', vert=False)

pie

.pie(column: str, labels: Optional[str] = None,
     autopct: str = '%1.1f%%', startangle: float = 90,
     explode: Optional[List[float]] = None) -> Chart
chart.pie('part', labels='region', explode=[0.05, 0, 0, 0])

heatmap

.heatmap(annot: bool = True, cmap: str = 'viridis',
         fmt: str = '.2f', cbar: bool = True) -> Chart

Matrice de corrélation de Pearson sur toutes les colonnes numériques du DataFrame.

chart.heatmap(cmap='coolwarm', fmt='.1f')

area

.area(x: str, y: Union[str, List[str]],
      alpha: float = 0.7, stacked: bool = False) -> Chart
chart.area('annee', ['rock', 'pop', 'jazz'], stacked=True)

violin

.violin(columns: Union[str, List[str]]) -> Chart
chart.violin(['groupe_A', 'groupe_B', 'groupe_C'])

lollipop

.lollipop(x: str, y: str, group: str,
          colors: Dict[str, str], order: Optional[List[str]] = None,
          shift_step: float = 0.2) -> Chart

Lollipop groupé — bulle dimensionnée + tige pointillée. x doit être numérique.

Paramètre Défaut Description
colors — {valeur_groupe: couleur}
order None Ordre d’affichage des groupes
shift_step 0.2 Décalage horizontal entre groupes 
chart.lollipop('year', 'n', 'status',
               colors={'cat1': '#e63946', 'cat2': '#457b9d'})

ombrothermic

.ombrothermic(month_col: str, temperature_col: str, precipitation_col: str,
              temp_color: str = 'tab:red', precip_color: str = 'tab:blue',
              dry_period_color: str = 'red', dry_period_alpha: float = 0.2,
              show_threshold_line: bool = True,
              temp_scale_factor: float = 2.0, kind: str = 'bars',
              hatch: str = '///', humid_fill: bool = True) -> Chart

Diagramme ombrothermique de Bagnouls et Gaussen (convention P = 2T). Les périodes où précipitations < temp_scale_factor × température sont des périodes sèches.

  • kind='bars' (défaut) : barres de précipitations, périodes sèches surlignées.
  • kind='lines' : deux courbes, périodes sèches hachurées entre les courbes (hatch règle le motif), période humide légèrement colorée (humid_fill). Mois secs : chart.dry_months.
chart.ombrothermic('mois', 'Température (°C)', 'Précipitations (mm)')
chart.ombrothermic('mois', 'Température (°C)', 'Précipitations (mm)', kind='lines')

print_ombrothermic_analysis

.print_ombrothermic_analysis(month_col: str, temperature_col: str,
                              precipitation_col: str,
                              temp_scale_factor: float = 2.0) -> Chart

Affiche dans la console une analyse mois par mois et retourne self.

radar

.radar(columns: List[str], group: Optional[str] = None,
       alpha: float = 0.25) -> Chart

Graphique araignée sur axe polaire. Chaque colonne = un rayon.

chart.radar(['vitesse', 'force', 'agilité', 'endurance'], group='equipe')

waterfall

.waterfall(x: str, y: str,
           positive_color: str = 'steelblue',
           negative_color: str = 'salmon') -> Chart

Barres cumulatives — très utilisé en finance et en budget.

chart.waterfall('poste', 'delta', positive_color='#2a9d8f', negative_color='#e76f51')

bump

.bump(x: str, y: str, group: str, linewidth: float = 2.5, markersize: float = 8,
      values: bool = False, curve_force: float = 0.5, highlight: list = None,
      end_labels: bool = True, ordinal: bool = False) -> Chart     # → chart.ranks

Graphique de classement en courbes lissées (bumplot). y : rangs (1 = premier) ou valeurs avec values=True ; curve_force de 0 (droit) à 1 ; highlight met des groupes en couleur (les autres en gris) ; ordinal écrit « 1er, 2e… ».

chart.bump('saison', 'classement', 'equipe')
chart.bump('annee', 'production', 'pays', values=True, highlight=['Sénégal'], ordinal=True)

ridgeline

.ridgeline(value_col: str, group_col: str,
           overlap: float = 1.5, alpha: float = 0.7) -> Chart

Distributions KDE superposées, une crête par groupe (le premier en haut). Toutes les densités partagent la même échelle, quelles que soient les unités de value_col.

Paramètre Défaut Description
overlap 1.5 Hauteur de la plus haute crête, en lignes (1 = touche la ligne du dessus) 
chart.ridgeline('salaire', 'secteur', overlap=2.0)

treemap

.treemap(values: str, labels: Optional[str] = None,
         alpha: float = 0.8) -> Chart

Rectangles imbriqués dimensionnés par une colonne. Nécessite squarify.

chart.treemap('budget', labels='departement')

hexbin

.hexbin(x: str, y: str, gridsize: int = 30,
        cmap: str = 'YlOrRd', mincnt: int = 1) -> Chart

Remplacement du scatter pour les gros volumes — chaque hexagone est coloré par densité de points.

chart.hexbin('age', 'revenu', gridsize=50, cmap='Blues')

parallel_coordinates

.parallel_coordinates(columns: List[str],
                       group: Optional[str] = None,
                       alpha: float = 0.4) -> Chart

Chaque colonne devient un axe vertical normalisé [0, 1]. Chaque ligne du DataFrame est une polyligne.

chart.parallel_coordinates(['puissance', 'conso', 'poids'], group='marque', alpha=0.3)

dumbbell

.dumbbell(y: str, x_start: str, x_end: str,
          color_start: str = 'steelblue', color_end: str = 'salmon',
          line_color: str = '#aaaaaa', markersize: float = 80,
          linewidth: float = 2.0) -> Chart

Comparaison avant/après — un haltère horizontal par catégorie.

chart.dumbbell('pays', 'pib_2020', 'pib_2024',
               color_start='#457b9d', color_end='#e63946')

circle_packing

.circle_packing(values: str, labels: str = None, group: str | List[str] = None,
                show_labels: bool = True, show_values: bool = False,
                alpha: float = 0.85, min_label_radius: float = 0.05) -> Chart

Cercles imbriqués (circlify) : un cercle par ligne, d’aire proportionnelle à values (valeurs positives). group regroupe les cercles par niveau (une colonne ou une liste). Les cercles (position, rayon, niveau, étiquette) sont dans chart.circles.

chart.circle_packing('surface', labels='culture', group='famille', show_values=True)

streamgraph

.streamgraph(x: str, y: Union[str, List[str]],
             alpha: float = 0.85) -> Chart

Aires empilées avec ligne de base centrée (wiggle) — esthétique pour l’évolution temporelle.

chart.streamgraph('annee', ['rock', 'pop', 'jazz', 'hip-hop'])

gantt

.gantt(task: str, start: str, end: str,
       group: Optional[str] = None, alpha: float = 0.8) -> Chart

Barres horizontales positionnées par décalage depuis la date de début minimale. start et end sont passées à pd.to_datetime — tous les formats de date sont acceptés.

chart.gantt('tache', 'debut', 'fin', group='equipe')

calendar_heatmap

.calendar_heatmap(date_col: str, value_col: str,
                  cmap: str = 'YlGn') -> Chart

Grille style GitHub contributions : semaines en colonnes, jours en lignes. Les jours manquants sont remplis à 0.

chart.calendar_heatmap('date', 'commits', cmap='Greens')

sankey

.sankey(flows: str, labels: str,
        orientations: Optional[str] = None,
        unit: str = '', scale: float = 0.01) -> Chart

Flux entre catégories via matplotlib.sankey.Sankey. Valeurs positives = entrées, négatives = sorties.

Paramètre Défaut Description
orientations None Colonne d’orientations (0 = droite, 1 = haut, −1 = bas)
scale 0.01 Facteur global — plus petit = flèches plus larges 
chart.sankey('flux', 'etiquette', orientations='direction', unit=' k€')

Sciences & analyse de données

Exemples complets dans les pages Comparaison, Relation, Multivarié et Climat & sols. L’argument error vaut 'se' (erreur type), 'sd' (écart-type) ou 'ci95' (IC à 95 %).

regression

.regression(x: str, y: str, order: int = 1, ci: bool = True,
            show_equation: bool = True, color: str = None,
            alpha: float = 0.7) -> Chart

Nuage de points + ajustement polynomial de degré order, bande de confiance à 95 %, équation et R² (p-value si order=1). Résultats : chart.regression_stats (coefs, r2, p, n).

chart.regression('dose', 'rendement', order=2)

mean_bar

.mean_bar(x: str, y: str, hue: str = None, error: str = 'se',
          points: bool = False, letters: bool = False, alpha_test: float = 0.05,
          capsize: float = 4, alpha: float = 0.85) -> Chart

Moyennes de y par niveau de x avec barres d’erreur ; hue ajoute un second facteur (barres groupées), points=True superpose les observations. letters=True affiche les lettres du test de Tukey HSD (même lettre = pas de différence significative au seuil alpha_test) — entre niveaux de x, ou entre groupes hue dans chaque niveau de x. Lettres : chart.tukey_letters.

chart.mean_bar('dose', 'rendement', hue='variete', error='ci95', letters=True)

interaction

.interaction(x: str, trace: str, response: str,
             error: str = 'se', marker: str = 'o') -> Chart

Réponse moyenne selon x, une ligne par niveau de trace (error=None : sans barres).

chart.interaction('dose', 'variete', 'rendement')

qqplot

.qqplot(column: str, color: str = None) -> Chart

Diagramme quantile-quantile face à la loi normale, avec le coefficient r de la droite.

pca_biplot

.pca_biplot(columns: List[str] = None, group: str = None, scale: bool = True,
            arrows: bool = True, alpha: float = 0.8) -> Chart

ACP (normée si scale=True) : individus sur CP1/CP2 et variables en flèches. Résultats : chart.pca (explained_variance_ratio, scores, loadings).

chart.pca_biplot(group='cycle')
chart.pca['loadings']

dendrogram

.dendrogram(labels: str = None, columns: List[str] = None, method: str = 'ward',
            metric: str = 'euclidean', color_threshold: float = None,
            standardize: bool = True, orientation: str = 'top',
            leaf_rotation: float = 90) -> Chart

Classification hiérarchique (scipy). color_threshold colore les groupes sous la hauteur de coupe et trace la ligne de coupe. Matrice de liaison : chart.linkage.

chart.dendrogram(labels='variete', method='average', color_threshold=4)

ternary

.ternary(a: str, b: str, c: str, group: str = None, grid_step: float = 0.1,
         alpha: float = 0.85, size: float = 40) -> Chart

Diagramme ternaire ; chaque ligne est normalisée à 100 %. Sommets : a en bas à gauche, b en bas à droite, c en haut. Graduations selon la convention USDA : c sur le bord gauche, b sur le bord droit, a en bas.

chart.ternary('sable', 'limon', 'argile', group='zone')

soil_texture

.soil_texture(sand: str, silt: str, clay: str, group: str = None,
              show_classes: bool = True, fill: bool = True, **kwargs) -> Chart

Triangle des textures USDA : les 12 classes tracées et nommées, et les échantillons. Classe de chaque ligne : chart.texture_classes. Hors graphique, la fonction texture_class(sable, limon, argile) accepte des nombres ou des colonnes.

from plutovizu import texture_class
chart.soil_texture('sable', 'limon', 'argile', group='zone')
df['texture'] = texture_class(df['sable'], df['limon'], df['argile'])

clustermap

.clustermap(columns: List[str] = None, labels: str = None, standardize: bool = True,
            cmap: str = None, method: str = 'ward', figsize: Tuple = None,
            **kwargs) -> Chart

Carte de chaleur avec dendrogrammes sur les lignes et les colonnes (seaborn.clustermap). Crée sa propre figure ; la grille seaborn est dans chart.sns_grid.

Types matplotlib

Les types de graphiques du catalogue matplotlib (plot types) qui n’avaient pas encore d’équivalent dans plutovizu. Les exemples sont dans les pages de la galerie.

Données appariées et temporelles

.step(x, y: str | List[str], where='mid', fill=False, alpha=0.2)          # escalier (step, stairs)
.stem(x, y, baseline=0.0, color=None)                                     # bâtons
.band(x, low, high, y=None, color=None, alpha=0.25, label=None)           # bande (fill_between)
.timeline(date, label, levels=None, color=None)                           # frise chronologique
.eventplot(time, group=None, linelength=0.7, linewidth=1.5)               # événements (eventplot)

Les dates en abscisse sont formatées de façon compacte automatiquement.

Distributions et erreurs

.errorbar(x, y, yerr=None, xerr=None, group=None, capsize=3, marker='o', line=False)
.hist2d(x, y, bins=30, cmap=None, colorbar=True)
.bihistogram(column, group, bins=20, horizontal=False, alpha=0.85)        # 2 groupes dos à dos

yerr / xerr : nom de colonne ou constante. bihistogram(..., horizontal=True) donne une pyramide des âges.

Relations

.confidence_ellipse(x, y, group=None, level=0.95, show_points=True, fill=True, alpha=0.15)
.pivot_heatmap(x, y, value, aggfunc='mean', annot=True, fmt='.1f', cmap=None)

confidence_ellipse : ellipse couvrant level de la population (loi normale bivariée). pivot_heatmap : tableau croisé coloré, conservé dans chart.pivot_table.

Composition et polaire

.donut(values, labels=None, group=None, hole=0.55, center_text=None, show_values=True)
.polar(theta, r, kind='bar', group=None, degrees=True, compass=False, alpha=0.85)
.radial_bar(values, labels=None, max_value=100, width=0.12, gap=0.04, show_values=True)
.progress_bar(value: str | float, total=100, labels=None, color=None, height=0.5)

donut(group=...) : anneaux imbriqués. polar : 'bar' (rose ; empilée par group, rose des vents avec compass=True), 'line' ou 'scatter' ; theta en catégories ou en degrés.

Champs

.contour(x, y, z, filled=True, levels=10, cmap=None, show_points=False,
         show_mesh=False, labels=True, colorbar=True)
.mesh(x, y, z, cmap=None, colorbar=True, show_points=False)
.vector_field(x, y, u, v, kind='quiver', cmap=None, density=1.2, colorbar=True)

Une grille régulière complète de (x, y) est détectée automatiquement (contourf, pcolormesh) ; sinon les points sont triangulés (tricontourf, tripcolor, maillage avec show_mesh=True). vector_field : 'quiver' (flèches), 'barbs' (barbules de vent) ou 'stream' (lignes de courant, grille régulière).

3D

.scatter3d(x, y, z, group=None, size=30, alpha=0.8)
.line3d(x, y, z, group=None)
.surface(x, y, z, kind='surface', cmap=None, colorbar=True)    # 'surface', 'wireframe', 'trisurf'
.bar3d(x, y, z, alpha=0.9)

Ces méthodes remplacent l’axe du graphique par un axe 3D (chart.ax). surface triangule automatiquement des points dispersés (trisurf).

Climat & sols

Exemples dans la page Climat & sols. Les couleurs conventionnelles (température rouge, pluie bleue, déficit orange) sont réglables par paramètre.

.walter_lieth(month, temp, precip, tmin=None, station=None,
              temp_color='#d1495b', precip_color='#2e86de')        # → chart.climate_summary
.climogram(precip, temp, month=None, group=None, labels=True)
.water_balance(month, precip, etp, show_bars=True,
               surplus_color='#2e86de', deficit_color='#e67e22')   # → chart.water_table, water_summary
.degree_days(date, tmin, tmax, base=10.0, cap=None, stages=None, color=None)
                                                                   # → chart.gdd, chart.stage_dates
.wind_rose(direction, speed, sectors=16, speed_bins=None, unit='m/s', cmap=None)
                                                                   # → chart.wind_table
.anomaly(x, value, baseline=None, window=None,
         pos_color='#d6604d', neg_color='#4393c3')                 # → chart.anomalies
.climate_stripes(x, value, cmap='RdBu_r', show_years=True)
.soil_profile(top, bottom, horizon, profile=None, color=None, width=0.6, show_labels=True)
.depth_profile(depth, value, group=None, marker='o')
.soil_properties(depth, columns, bottom=None, group=None, marker='o')  # → chart.axes
.retention_curve(suction, water, group=None, unit='pF', fit=True,
                 field_capacity=2.5, wilting_point=4.2)            # → chart.retention
.grain_size_curve(diameter, passing, group=None, limits=(0.002, 0.05, 2.0),
                  names=('Argile', 'Limon', 'Sable', 'Graviers'))  # → chart.grain_size
.exchange_complex(horizon, cations, acidity=None, cec=None,
                  show_saturation=True)                            # → chart.base_saturation
.infiltration_curve(time, cumulative, model='philip', show_rate=True)
                                                                   # → chart.infiltration, chart.ax2
.isopleth(time, depth, value, levels=10, cmap=None, contour_labels=True)
  • walter_lieth : 10 °C ↔︎ 20 mm, pluies comprimées au 1/10 au-delà de 100 mm ; tmin marque les mois de gel.
  • degree_days : DJ = max(0, (min(Tmax, cap) + Tmin) / 2 − base) ; stages = {stade: DJ}.
  • anomaly : baseline = moyenne (défaut), nombre, ou période (début, fin) de x.
  • wind_rose : directions en degrés (0 = nord), vitesses regroupées selon speed_bins.
  • retention_curve : ajustement de van Genuchten θ(h) = θr + (θs − θr) / (1 + (αh)ⁿ)^(1−1/n) (h en cm, scipy) ; unit = ‘pF’, ‘kPa’ ou ‘cm’ ; réserve utile = θ(pF 2,5) − θ(pF 4,2).
  • grain_size_curve : diamètres en mm ; Cu = D60/D10, Cc = D30²/(D10·D60).
  • exchange_complex : V = S/T, T = cec ou S + acidity.
  • infiltration_curve : model='philip' (I = S√t + At) ou 'horton' ; vitesse finale = A ou fc.
  • soil_properties : avec bottom, depth est le haut de l’horizon (tracé en paliers).

Écologie

Exemples dans la page Écologie. Calculs utilisables sans graphique : from plutovizu import glm_fit, ordinate, diversity_indices (et plutovizu.ecology).

           show_stats=True)                                   # → chart.glm

                random_state=0)                               # → chart.response

             log=False, sort=False)                           # → chart.forest_table
.ordination(species, env=None, method='ca', labels=None, group=None, show_species=True,
            axes=(1, 2), scale=False)                         # → chart.ord
.rank_abundance(species, labels=None, pooled=False, log=True, marker='o')

.diversity(species, index='shannon', labels=None, group=None, letters=False, color=None)
                                                              # → chart.diversity_table
  • glm_curve : GLM à lien canonique (logit, log) ajusté par moindres carrés pondérés itératifs ; degree=2 → réponse en cloche et optimum. chart.glm : coefficients, erreurs types, déviances, D², AIC, p-value (rapport de vraisemblance).
  • response_curve : LOWESS (noyau tricube), bande à 95 % par bootstrap, optimum.
  • count_distribution : lois de Poisson et binomiale négative (méthode des moments) de même moyenne ; rapport variance / moyenne et part de zéros.
  • forest_plot : lower/upper, ou se (± 1,96 se) ; log=True et ref=1 pour des rapports.
  • ordination : species = colonnes d’abondance (une ligne par site), env = variables environnementales (obligatoires pour 'cca' et 'rda'). Échelle symétrique ; les espèces et les flèches sont remises à l’échelle des sites pour la lisibilité.
  • accumulation : kind='sites' (permutations, Chao2) ou 'individuals' (raréfaction de Hurlbert par site).
  • diversity : index parmi 'richesse', 'shannon' (log népérien), 'simpson' (1 − Σp²), 'inv_simpson', 'pielou'.
