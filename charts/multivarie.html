Multivarié & classification

Résumer beaucoup de variables et regrouper les individus qui se ressemblent.

Tous les exemples utilisent le thème editorial ; chaque graphique suit le thème actif (set_theme(...)). Retour à la galerie.

pca_biplot — Analyse en composantes principales

Biplot d’analyse en composantes principales : les individus sur les deux premiers axes (points colorés par groupe) et les variables en flèches.

Quand l’utiliser. Résumer de nombreuses variables numériques corrélées en deux axes, voir quelles variables opposent les individus et quels individus se ressemblent.

Données attendues : un DataFrame, une ligne par individu, des colonnes numériques.

Colonne (exemple) Type Rôle Exemple de valeur
variete texte identifiant (non utilisé dans le calcul) V07
hauteur nombre columns : variable de l’ACP 118
rendement nombre columns : variable de l’ACP 4.9
cycle texte group (optionnel) : couleur des points Précoce

Paramètres

Paramètre Défaut Description
columns None Colonnes numériques de l’ACP ; None = toutes les colonnes numériques.
group None Colonne de groupe (couleurs + légende).
scale True Centre-réduit les variables (indispensable si leurs unités diffèrent).
arrows True Dessine les variables en flèches.
alpha 0.8 Opacité, de 0 (transparent) à 1 (opaque).

Résultats calculés : chart.pca : variance expliquée, coordonnées des individus et des variables.

Exemple

ACP normée : les individus sur les deux premiers axes, colorés par groupe, et les variables en flèches. Variance expliquée, coordonnées et contributions dans chart.pca.

rng = np.random.default_rng(7)
n = 30
precocite = rng.normal(size=n)
caracteres = pd.DataFrame({
    'variete':   [f'V{i:02d}' for i in range(n)],
    'cycle':     np.where(precocite > 0, 'tardif', 'précoce'),
    'hauteur':   95 + 12 * precocite + rng.normal(0, 5, n),
    'jours_floraison': 85 + 10 * precocite + rng.normal(0, 3, n),
    'talles':    12 - 2 * precocite + rng.normal(0, 1, n),
    'pmg':       25 + rng.normal(0, 2.5, n),
    'rendement': 4.5 + 0.5 * precocite + rng.normal(0, 0.4, n),
})

chart = (Chart(caracteres, figsize=(8, 6))
    .pca_biplot(group='cycle')
    .title('ACP des caractères variétaux')
    .tight_layout())
print('Variance expliquée :', (chart.pca['explained_variance_ratio'][:3] * 100).round(1), '%')
chart.show()
Variance expliquée : [65.9 20.1  8.6] %

dendrogram — Classification hiérarchique

Dendrogramme de classification hiérarchique : les individus sont regroupés pas à pas, la hauteur des branches mesurant la distance entre groupes.

Quand l’utiliser. Former des groupes d’individus semblables (variétés, sites, clients) et choisir le nombre de groupes en coupant l’arbre.

Données attendues : un DataFrame, une ligne par individu, des colonnes numériques.

Colonne (exemple) Type Rôle Exemple de valeur
variete texte labels : nom des feuilles V07
hauteur nombre columns : variable 118
rendement nombre columns : variable 4.9

Paramètres

Paramètre Défaut Description
labels None Colonne des étiquettes (noms affichés).
columns None Colonnes numériques utilisées ; None = toutes.
method 'ward' Méthode d’agrégation : ‘ward’, ‘average’, ‘complete’, ‘single’…
metric 'euclidean' Distance entre individus : ‘euclidean’, ‘cityblock’, ‘correlation’…
color_threshold None Hauteur de coupe ; les branches sous ce seuil partagent une couleur.
standardize True Centre-réduit les variables avant le calcul des distances.
orientation 'top' Sens de l’arbre : ‘top’, ‘bottom’, ‘left’ ou ‘right’.
leaf_rotation 90 Rotation des noms des feuilles (degrés).

Exemple

Regroupe les individus selon leur ressemblance (méthode de Ward par défaut, variables centrées-réduites). color_threshold colore les groupes formés sous la hauteur de coupe, marquée par une ligne pointillée.

(Chart(caracteres, figsize=(11, 5))
    .dendrogram(labels='variete', color_threshold=6)
    .title('Dendrogramme des variétés (Ward)')
    .tight_layout()
    .show())

clustermap — Carte de chaleur classée

Carte de chaleur des données avec un dendrogramme sur les lignes et un sur les colonnes, réordonnées selon la classification (seaborn clustermap).

Quand l’utiliser. Voir à la fois les groupes d’individus et les groupes de variables, et ce qui les caractérise (profils d’expression, de traits, de sites).

Données attendues : un DataFrame, une ligne par individu, des colonnes numériques.

Colonne (exemple) Type Rôle Exemple de valeur
variete texte labels : nom des lignes V07
hauteur nombre columns : colonne de la matrice 118
talles nombre columns : colonne de la matrice 14

Paramètres

Paramètre Défaut Description
columns None Colonnes numériques ; None = toutes.
labels None Colonne nommant les lignes.
standardize True Centre-réduit chaque colonne (couleurs comparables entre variables).
cmap None Défaut ‘vlag’ si standardisé, sinon celle du thème.
method 'ward' Méthode d’agrégation de la classification (‘ward’, ‘average’…).
figsize None Taille de la figure créée par seaborn (pouces) ; None = celle du Chart.
**kwargs — Options supplémentaires transmises à la fonction sous-jacente (seaborn ou matplotlib).

Exemple

Classe à la fois les individus (lignes) et les variables (colonnes), avec leurs dendrogrammes. Les colonnes sont centrées-réduites par défaut (standardize=True).

(Chart(caracteres, figsize=(8, 9))
    .clustermap(labels='variete')
    .title('Clustermap des caractères variétaux')
    .show())
