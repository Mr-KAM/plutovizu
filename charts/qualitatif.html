Analyse qualitative

Réponses ouvertes, entretiens et questionnaires d’opinion.

Tous les exemples utilisent le thème editorial ; chaque graphique suit le thème actif (set_theme(...)). Retour à la galerie.

word_cloud — Nuage de mots

Nuage de mots : les mots les plus fréquents d’un texte, de taille proportionnelle à leur fréquence ; mots vides français retirés.

Quand l’utiliser. Premier aperçu de réponses ouvertes, d’entretiens ou de commentaires. Pour comparer précisément les fréquences, compléter par word_frequency.

Données attendues : un DataFrame, une ligne par réponse (colonne de texte) — ou une ligne par mot avec son poids.

Colonne (exemple) Type Rôle Exemple de valeur
reponse texte text : texte libre analysé Les semences arrivent trop tard

Paramètres

Paramètre Défaut Description
text None Colonne de texte dont on compte les mots.
words None Colonne de mots déjà comptés (avec weights), à la place de text.
weights None Colonne des poids (fréquences) des mots de words.
max_words 150 Nombre maximal de mots affichés.
language 'fr' Langue des mots vides retirés (‘fr’ ou ‘en’).
stopwords None Mots supplémentaires à ignorer (liste).
min_length 3 Longueur minimale des mots retenus.
ngram 1 Taille des expressions comptées (1 = mots, 2 = paires de mots…).
shape 'rectangle' Forme du nuage : ‘rectangle’ ou ‘circle’.
colormap None Palette continue des mots ; None = couleurs du thème.
random_state 42 Graine du hasard, pour un résultat reproductible.

Résultats calculés : chart.word_frequencies : fréquence de chaque mot.

Exemple

À partir d’une colonne de texte libre : les mots sont comptés en ignorant les mots vides français (language='fr', ou 'en', 'fr+en'). On peut ajouter ses propres mots à ignorer (stopwords=[...]), compter des expressions (ngram=2), ou fournir directement des fréquences (words=, weights=). Couleurs et police suivent le thème.

(Chart(enquete, figsize=(10, 5))
    .word_cloud('reponse')
    .title('Difficultés citées par les producteurs')
    .show())
with theme_context('prezi'):
    (Chart(enquete, figsize=(7, 7))
        .word_cloud('reponse', ngram=2, shape='circle')
        .title('Expressions les plus fréquentes')
        .show())

word_frequency — Fréquence des mots

Barres horizontales des mots (ou expressions) les plus fréquents d’une colonne de texte.

Quand l’utiliser. Quantifier les thèmes qui reviennent dans des réponses ouvertes ; le complément chiffré du nuage de mots.

Données attendues : un DataFrame, une ligne par réponse.

Colonne (exemple) Type Rôle Exemple de valeur
reponse texte text : texte libre analysé Manque d’eau en saison sèche

Paramètres

Paramètre Défaut Description
text obligatoire Colonne de texte.
top 20 Nombre de mots affichés.
ngram 1 Taille des expressions comptées (1 = mots, 2 = paires de mots…).
language 'fr' Langue des mots vides retirés (‘fr’ ou ‘en’).
stopwords None Mots supplémentaires à ignorer.
min_length 3 Longueur minimale des mots retenus.
color None Couleur unique (nom, hexadécimal). None : couleur du thème.
show_values True Écrit les valeurs sur le graphique.

Exemple

Le complément chiffré du nuage : les mots (ou expressions) les plus cités, en barres. Les fréquences sont dans chart.word_frequencies ; la fonction word_counts() les calcule sans tracer.

(Chart(enquete, figsize=(9, 5))
    .word_frequency('reponse', top=12)
    .title('Mots les plus cités')
    .tight_layout()
    .show())

likert — Échelle de Likert

Barres empilées divergentes : une barre par question, centrée sur la réponse neutre, désaccord à gauche, accord à droite (en %).

Quand l’utiliser. Présenter les résultats d’un questionnaire à échelle de Likert (satisfaction, accord, fréquence) et comparer les questions.

Données attendues : un DataFrame, une ligne par répondant, une colonne par question (réponses en texte).

Colonne (exemple) Type Rôle Exemple de valeur
Q1 texte columns : une question D’accord
Q2 texte columns : autre question Neutre

Paramètres

Paramètre Défaut Description
columns obligatoire Une colonne par question.
order obligatoire Liste des modalités, de la plus négative à la plus positive.
labels None Libellés des questions {colonne: texte}.
cmap 'RdYlGn' Palette divergente (rouge → vert par défaut).
sort True Trie les questions par niveau d’accord.
show_values True Écrit les valeurs sur le graphique.
min_label 5 Pourcentage sous lequel la valeur n’est pas écrite.

Résultats calculés : chart.likert_table : pourcentages par question et modalité.

Exemple

Une barre par question, centrée sur la réponse neutre : désaccord à gauche, accord à droite, en pourcentage. Les questions sont triées par accord net.

echelle = ['Pas du tout d’accord', 'Pas d’accord', 'Neutre', 'D’accord', 'Tout à fait d’accord']
opinions = pd.DataFrame({q: rng.choice(echelle, 80, p=p) for q, p in {
    'La formation était utile':      [.05, .10, .15, .40, .30],
    'Les semences sont accessibles': [.25, .30, .20, .15, .10],
    'Le crédit arrive à temps':      [.35, .30, .15, .15, .05],
    'Je recommande le projet':       [.05, .05, .20, .35, .35],
}.items()})

(Chart(opinions, figsize=(10, 4.5))
    .likert(list(opinions.columns), order=echelle)
    .title('Satisfaction des producteurs')
    .tight_layout()
    .show())

code_matrix — Matrice des codes

Matrice des codes : nombre de fois où chaque code (thème) apparaît dans chaque cas (entretien, document, groupe), en carte de chaleur aux cases arrondies (rounded(0) : cases vives).

Quand l’utiliser. Analyse qualitative codée (type NVivo / Atlas.ti) : comparer les thèmes abordés par chaque entretien ou catégorie d’acteurs.

Données attendues : un DataFrame, une ligne par segment codé.

Colonne (exemple) Type Rôle Exemple de valeur
entretien texte case : cas (ligne de la matrice) E04
code texte code : thème (colonne de la matrice) Accès au crédit

Paramètres

Paramètre Défaut Description
case obligatoire Colonne des cas (entretiens, documents).
code obligatoire Colonne des codes attribués aux segments.
normalize False Pourcentages par cas au lieu des effectifs.
annot True Écrit les valeurs dans les cases.
cmap None Palette de couleurs continue (nom matplotlib). None : celle du thème.

Résultats calculés : chart.code_table : le tableau cas × codes.

Exemple

Pour le codage d’entretiens (comme dans NVivo ou Atlas.ti) : une ligne par segment codé, et la matrice montre combien de fois chaque code apparaît dans chaque entretien. normalize=True donne la part de chaque code dans l’entretien.

segments = pd.DataFrame({
    'entretien': rng.choice([f'Entretien {i}' for i in range(1, 7)], 120),
    'code': rng.choice(['Eau', 'Prix', 'Crédit', 'Semences', 'Formation', 'Marché'], 120,
                       p=[.25, .2, .15, .15, .1, .15]),
})

(Chart(segments, figsize=(9, 4.5))
    .code_matrix('entretien', 'code')
    .title('Matrice des codes')
    .tight_layout()
    .show())
