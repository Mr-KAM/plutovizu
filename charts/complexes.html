Graphiques complexes

Graphiques non triviaux : plusieurs couches, plusieurs axes ou plusieurs panneaux.

Ces graphiques superposent plusieurs informations : un cumul sur un second axe (Pareto), des limites calculées (carte de contrôle, Bland-Altman), deux niveaux de composition (Marimekko), ou une grille de panneaux (seaborn). Tous les exemples utilisent le thème editorial. Retour à la galerie.

Analyse et aide à la décision

pareto — Diagramme de Pareto

Diagramme de Pareto : catégories triées par valeur décroissante (barres) et pourcentage cumulé (courbe, axe de droite), avec le seuil de la règle des 80/20. Les catégories « essentielles », celles qu’il faut pour atteindre le seuil, sont en couleur pleine.

Quand l’utiliser. Hiérarchiser les causes d’un problème (pertes post-récolte, défauts, pannes, erreurs, plaintes) pour concentrer l’effort sur le petit nombre qui pèse le plus.

Données attendues : un DataFrame, une ligne par catégorie (avec value), ou une ligne par événement (comptage).

Colonne (exemple) Type Rôle Exemple de valeur
cause texte category : catégorie (cause, défaut, type d’erreur) Moisissures
tonnes nombre value (optionnel) : valeur à sommer ; sinon les lignes sont comptées 141

Paramètres

Paramètre Défaut Description
category obligatoire Colonne des catégories (causes, défauts, types d’erreur).
value None Colonne des valeurs à sommer ; None : nombre de lignes.
cutoff 80.0 Seuil du pourcentage cumulé (%), 80 pour la règle des 80/20.
show_values True Écrit la valeur au-dessus de chaque barre.
color None Couleur des barres ; None : 1re couleur du thème.
line_color None Couleur de la courbe cumulée ; None : 2e couleur du thème.

Résultats calculés : chart.pareto_table : valeur, part (%), cumul (%) et classe (‘essentielle’ ou ‘secondaire’) de chaque catégorie ; chart.ax2 : l’axe du cumul.

Exemple

chart = (Chart(pertes)
    .pareto('cause', 'tonnes')
    .title('Pertes post-récolte : 4 causes font 80 % des pertes')
    .tight_layout())
chart.show()
chart.pareto_table

Sans value, chaque ligne compte pour un : on part directement du registre des incidents. cutoff change le seuil.

incidents = pertes.loc[pertes.index.repeat(pertes['tonnes'] // 5), ['cause']]
(Chart(incidents)
    .pareto('cause', cutoff=70)
    .title("Registre d'incidents, seuil 70 %")
    .tight_layout()
    .show())

control_chart — Carte de contrôle

Carte de contrôle de Shewhart aux valeurs individuelles : la série, sa moyenne et les limites de contrôle à ± 3 σ (σ estimé par l’étendue mobile moyenne, MR/1,128) ; les points hors limites sont mis en évidence.

Quand l’utiliser. Suivre la stabilité d’un procédé (humidité des lots, poids des sacs, température d’un séchoir, rendement d’une chaîne) et repérer les dérives à expliquer.

Données attendues : un DataFrame, une ligne par mesure, dans l’ordre de prise.

Colonne (exemple) Type Rôle Exemple de valeur
lot nombre ou date x : ordre des mesures 12
humidite nombre y : valeur mesurée 13.4

Paramètres

Paramètre Défaut Description
x obligatoire Colonne de l’ordre des mesures (date, lot, numéro d’échantillon).
y obligatoire Colonne de la valeur mesurée.
sigma 3.0 Nombre d’écarts-types des limites (3 : limites de Shewhart).
zones True Trace aussi les zones à ±1 σ et ±2 σ (lignes pointillées).
color None Couleur de la série ; None : 1re couleur du thème.

Résultats calculés : chart.control_limits : moyenne, sigma, LSC et LIC ; chart.control_table : les mesures et la colonne hors_limites.

Exemple

chart = (Chart(lots)
    .control_chart('lot', 'humidite')
    .title('Humidité des lots : deux lots hors limites')
    .labels('Lot', 'Humidité (%)')
    .tight_layout())
chart.show()
chart.control_table[chart.control_table['hors_limites']]
lot humidite hors_limites
11 12 14.9 True
23 24 11.6 True
Note

σ est estimé par l’étendue mobile moyenne (MR/1,128) et non par l’écart-type global : une dérive ou un point aberrant élargit moins les limites. sigma=2 donne des limites d’alerte.

marimekko — Graphique Marimekko

Graphique Marimekko (mosaïque) : une barre empilée à 100 % par catégorie, de largeur proportionnelle à sa part du total. Deux niveaux de composition dans une seule figure.

Quand l’utiliser. Comparer la composition de groupes de tailles différentes : cultures par région selon la surface, ventes par marché et par produit, effectifs par site et par classe.

Données attendues : un DataFrame, une ligne par combinaison (colonne de la mosaïque × segment), ou une ligne par individu.

Colonne (exemple) Type Rôle Exemple de valeur
region texte x : colonne de la mosaïque (largeur = part du total) Nord
culture texte y : segment empilé Mil
surface nombre value (optionnel) : valeur à sommer 420

Paramètres

Paramètre Défaut Description
x obligatoire Colonne des colonnes de la mosaïque (largeur = part du total).
y obligatoire Colonne des segments empilés dans chaque colonne.
value None Colonne des valeurs à sommer ; None : nombre de lignes.
show_values True Écrit la part (%) dans les cases assez grandes.

Résultats calculés : chart.marimekko_table : le tableau croisé x × y.

Exemple

(Chart(assolement)
    .marimekko('region', 'culture', 'surface')
    .title('Assolement : la largeur donne le poids de chaque région')
    .tight_layout()
    .show())

bland_altman — Graphique de Bland-Altman

Graphique de Bland-Altman : accord entre deux méthodes de mesure. Chaque paire est placée selon sa moyenne et sa différence ; les lignes donnent le biais moyen et les limites d’agrément (biais ± 1,96 écart-type).

Quand l’utiliser. Valider une méthode rapide ou bon marché contre une méthode de référence : sonde contre gravimétrie, kit de terrain contre laboratoire, deux appareils, deux opérateurs.

Données attendues : un DataFrame, une ligne par individu mesuré par les deux méthodes.

Colonne (exemple) Type Rôle Exemple de valeur
gravimetrie nombre a : première méthode (référence) 18.4
sonde nombre b : seconde méthode 19.1

Paramètres

Paramètre Défaut Description
a obligatoire Colonne de la première méthode (souvent la méthode de référence).
b obligatoire Colonne de la seconde méthode, mesurée sur les mêmes individus.
limits 1.96 Multiplicateur de l’écart-type des limites d’agrément (1,96 : 95 %).
color None Couleur des points ; None : 1re couleur du thème.

Résultats calculés : chart.agreement : biais, écart-type, limites basse et haute, nombre de points hors limites, n.

Exemple

chart = (Chart(mesures)
    .bland_altman('gravimetrie', 'sonde')
    .title('Accord sonde / gravimétrie')
    .labels('Moyenne des deux méthodes (%)', 'Gravimétrie − sonde (%)')
    .tight_layout())
chart.show()

raincloud — Nuage de pluie

Graphique en nuage de pluie (raincloud) : pour chaque catégorie, une demi-densité (le nuage), une boîte à moustaches étroite et toutes les observations dessous (la pluie).

Quand l’utiliser. Comparer des distributions en montrant à la fois leur forme, leur résumé et chaque valeur : rendements par variété, mesures par traitement, notes par groupe.

Données attendues : un DataFrame, une ligne par observation.

Colonne (exemple) Type Rôle Exemple de valeur
variete texte x : catégorie IR-841
rendement nombre y : valeur mesurée 4.6

Paramètres

Paramètre Défaut Description
x obligatoire Colonne des catégories (une ligne par catégorie).
y obligatoire Colonne de la valeur mesurée (axe horizontal).
order None Ordre des catégories ; None : ordre d’apparition.
points True Affiche les observations (la « pluie »).

Exemple

(Chart(essai)
    .raincloud('variete', 'rendement')
    .title('Rendement par variété')
    .labels('Rendement (t/ha)', '')
    .tight_layout()
    .show())

Grilles seaborn

Les fonctions seaborn « figure » créent une grille de panneaux : title() devient le titre général, labels() s’applique à tous les panneaux et la grille est dans chart.sns_grid. Leur taille se règle avec height (hauteur d’un panneau, en pouces) et aspect (largeur / hauteur), pas avec figsize.

relplot — Grille de relations

Grille de nuages de points ou de courbes : un panneau par modalité de col et de row, une couleur par modalité de hue (seaborn relplot).

Quand l’utiliser. Comparer la même relation entre sites, années ou traitements, côte à côte et sur les mêmes échelles ; kind='line' trace la moyenne et son intervalle de confiance.

Données attendues : un DataFrame, une ligne par observation (format long).

Colonne (exemple) Type Rôle Exemple de valeur
dose nombre x 60
rendement nombre y 4.8
variete texte hue, col ou row (optionnels) Nerica-4

Paramètres

Paramètre Défaut Description
x obligatoire Colonne de l’axe horizontal.
y obligatoire Colonne de l’axe vertical.
hue None Colonne de regroupement : une couleur par modalité.
col None Colonne qui sépare les panneaux en colonnes.
row None Colonne qui sépare les panneaux en lignes.
kind 'scatter' ‘scatter’ (nuage) ou ‘line’ (courbe moyenne et intervalle de confiance).
**kwargs — Options supplémentaires transmises à la fonction sous-jacente (seaborn ou matplotlib).

Résultats calculés : chart.sns_grid : la grille seaborn (FacetGrid).

Exemple

(Chart(essai)
    .relplot('dose', 'rendement', col='variete', kind='line', marker='o', height=3.2, aspect=0.9)
    .title("Réponse à l'azote par variété")
    .labels('Dose N (kg/ha)', 'Rendement (t/ha)')
    .tight_layout()
    .show())

displot — Grille de distributions

Grille de distributions : histogrammes, densités ou fonctions de répartition, un panneau par modalité de col et de row (seaborn displot).

Quand l’utiliser. Comparer la distribution d’une variable entre groupes, superposée (hue) ou en panneaux (col), avec une estimation de densité (kde=True).

Données attendues : un DataFrame, une ligne par observation.

Colonne (exemple) Type Rôle Exemple de valeur
rendement nombre x : variable étudiée 4.8
variete texte hue, col ou row (optionnels) Nerica-4

Paramètres

Paramètre Défaut Description
x obligatoire Colonne de l’axe horizontal.
hue None Colonne de regroupement : une couleur par modalité.
col None Colonne qui sépare les panneaux en colonnes.
row None Colonne qui sépare les panneaux en lignes.
kind 'hist' ‘hist’ (histogramme), ‘kde’ (densité) ou ‘ecdf’ (répartition).
**kwargs — Options supplémentaires transmises à la fonction sous-jacente (seaborn ou matplotlib).

Résultats calculés : chart.sns_grid : la grille seaborn (FacetGrid).

Exemple

(Chart(essai)
    .displot('rendement', col='variete', kde=True, bins=8, height=3.2, aspect=0.9)
    .title('Distribution du rendement')
    .tight_layout()
    .show())

catplot — Grille par catégorie

Grille de graphiques par catégorie (points, essaim, boîtes, violons, boxen, moyennes, barres, effectifs), un panneau par modalité de col et de row (seaborn catplot).

Quand l’utiliser. Comparer des groupes selon un second, voire un troisième facteur : variétés par bloc, traitements par site, réponses par classe d’âge.

Données attendues : un DataFrame, une ligne par observation.

Colonne (exemple) Type Rôle Exemple de valeur
variete texte x : catégorie IR-841
rendement nombre y : valeur 4.6
bloc texte ou entier hue, col ou row (optionnels) 2

Paramètres

Paramètre Défaut Description
x obligatoire Colonne de l’axe horizontal.
y None Colonne de l’axe vertical.
hue None Colonne de regroupement : une couleur par modalité.
col None Colonne qui sépare les panneaux en colonnes.
row None Colonne qui sépare les panneaux en lignes.
kind 'strip' ‘strip’, ‘swarm’, ‘box’, ‘violin’, ‘boxen’, ‘point’, ‘bar’ ou ‘count’.
**kwargs — Options supplémentaires transmises à la fonction sous-jacente (seaborn ou matplotlib).

Résultats calculés : chart.sns_grid : la grille seaborn (FacetGrid).

Exemple

(Chart(essai.assign(dose=essai['dose'].astype(str)))
    .catplot('variete', 'rendement', hue='dose', kind='box', height=4, aspect=1.6,
             palette='crest')
    .title('Rendement par variété et par dose')
    .tight_layout()
    .show())

lmplot — Grille de régressions

Grille de régressions : nuage de points et droite (ou polynôme) ajustée avec sa bande de confiance, par groupe (hue) ou par panneau (col, row) (seaborn lmplot).

Quand l’utiliser. Comparer des relations dose-réponse ou des tendances entre groupes : la pente change-t-elle d’une variété ou d’un site à l’autre ?

Données attendues : un DataFrame, une ligne par observation.

Colonne (exemple) Type Rôle Exemple de valeur
dose nombre x 60
rendement nombre y 4.8
variete texte hue, col ou row (optionnels) Sahel-108

Paramètres

Paramètre Défaut Description
x obligatoire Colonne de l’axe horizontal.
y obligatoire Colonne de l’axe vertical.
hue None Colonne de regroupement : une couleur par modalité.
col None Colonne qui sépare les panneaux en colonnes.
row None Colonne qui sépare les panneaux en lignes.
order 1 Degré du polynôme ajusté (1 : droite, 2 : parabole).
**kwargs — Options supplémentaires transmises à la fonction sous-jacente (seaborn ou matplotlib).

Résultats calculés : chart.sns_grid : la grille seaborn (FacetGrid).

Exemple

(Chart(essai)
    .lmplot('dose', 'rendement', hue='variete', order=2, height=4, aspect=1.4)
    .title('Courbes de réponse ajustées')
    .labels('Dose N (kg/ha)', 'Rendement (t/ha)')
    .tight_layout()
    .show())

jointplot — Relation et distributions marginales

Nuage de points (ou densité, régression, hexagones) avec la distribution de chaque variable dans les marges (seaborn jointplot).

Quand l’utiliser. Étudier une relation entre deux variables en gardant un œil sur leurs distributions individuelles.

Données attendues : un DataFrame, une ligne par observation.

Colonne (exemple) Type Rôle Exemple de valeur
dose nombre x 90
rendement nombre y 5.2

Paramètres

Paramètre Défaut Description
x obligatoire Colonne de l’axe horizontal.
y obligatoire Colonne de l’axe vertical.
hue None Colonne de regroupement : une couleur par modalité.
kind 'scatter' Type du panneau central : ‘scatter’, ‘kde’, ‘hist’, ‘hex’, ‘reg’ ou ‘resid’.
**kwargs — Options supplémentaires transmises à la fonction sous-jacente (seaborn ou matplotlib).

Exemple

(Chart(essai)
    .jointplot('dose', 'rendement', kind='reg', height=5.5)
    .title('Rendement selon la dose')
    .show())

pairplot — Matrice de nuages de points

Matrice de graphiques : un nuage de points pour chaque paire de variables et la distribution de chaque variable sur la diagonale.

Quand l’utiliser. Exploration initiale d’un jeu de données à plusieurs variables numériques, coloré par groupe.

Données attendues : un DataFrame, une ligne par individu.

Colonne (exemple) Type Rôle Exemple de valeur
hauteur nombre vars : variable 118
rendement nombre vars : variable 4.9
cycle texte hue (optionnel) Tardif

Paramètres

Paramètre Défaut Description
vars None Liste des colonnes numériques à croiser ; None = toutes.
hue None Colonne de regroupement : une couleur par modalité.
corner False N’affiche que le triangle inférieur (pas de doublons).
**kwargs — Options supplémentaires transmises à la fonction sous-jacente (seaborn ou matplotlib).

Exemple

(Chart(caracteres)
    .pairplot(vars=['hauteur', 'jours_floraison', 'talles', 'rendement'],
              hue='cycle', corner=True, height=2)
    .title('Relations entre caractères')
    .show())

clustermap — Carte de chaleur classée

Carte de chaleur des données avec un dendrogramme sur les lignes et un sur les colonnes, réordonnées selon la classification (seaborn clustermap).

Quand l’utiliser. Voir à la fois les groupes d’individus et les groupes de variables, et ce qui les caractérise (profils d’expression, de traits, de sites).

Données attendues : un DataFrame, une ligne par individu, des colonnes numériques.

Colonne (exemple) Type Rôle Exemple de valeur
variete texte labels : nom des lignes V07
hauteur nombre columns : colonne de la matrice 118
talles nombre columns : colonne de la matrice 14

Paramètres

Paramètre Défaut Description
columns None Colonnes numériques ; None = toutes.
labels None Colonne nommant les lignes.
standardize True Centre-réduit chaque colonne (couleurs comparables entre variables).
cmap None Défaut ‘vlag’ si standardisé, sinon celle du thème.
method 'ward' Méthode d’agrégation de la classification (‘ward’, ‘average’…).
figsize None Taille de la figure créée par seaborn (pouces) ; None = celle du Chart.
**kwargs — Options supplémentaires transmises à la fonction sous-jacente (seaborn ou matplotlib).

Exemple

Classe à la fois les individus (lignes) et les variables (colonnes), avec leurs dendrogrammes. Les colonnes sont centrées-réduites par défaut (standardize=True).

(Chart(caracteres, figsize=(8, 9))
    .clustermap(labels='variete')
    .title('Clustermap des caractères variétaux')
    .show())

seaborn — N’importe quel graphique seaborn

Accès à toutes les fonctions de seaborn avec les données, le thème et le chaînage du Chart : les fonctions « axes » dessinent sur le graphique, les fonctions « figure » (pairplot, catplot…) créent leur propre grille.

Quand l’utiliser. Utiliser un graphique seaborn qui n’a pas de méthode dédiée (violinplot, swarmplot, lineplot avec intervalle, displot…), tout en gardant le thème et .title(), .save().

Données attendues : un DataFrame, le format attendu par la fonction seaborn choisie, en général le format long (une ligne par observation).

Colonne (exemple) Type Rôle Exemple de valeur
variete texte x : catégorie Nerica-4
rendement nombre y : valeur 5.3

Paramètres

Paramètre Défaut Description
name obligatoire Nom de la fonction seaborn, ex. ‘violinplot’, ‘swarmplot’, ‘lineplot’, ‘displot’.
**kwargs — Arguments de la fonction seaborn (x=, y=, hue=, inner=…) ; data est fourni automatiquement.

Exemple

(Chart(essai)
    .seaborn('violinplot', x='variete', y='rendement', hue='variete', inner='quart')
    .title('Distribution du rendement par variété')
    .tight_layout()
    .show())
