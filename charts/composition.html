Composition

Les parts d’un total, et l’avancement vers un objectif.

Tous les exemples utilisent le thème editorial ; chaque graphique suit le thème actif (set_theme(...)). Retour à la galerie.

pie — Camembert

Camembert : chaque part est un secteur d’angle proportionnel à sa valeur.

Quand l’utiliser. Montrer la répartition d’un total en peu de parts (2 à 6). Au-delà, ou pour comparer des valeurs proches, préférer des barres.

Données attendues : un DataFrame, une ligne par part.

Colonne (exemple) Type Rôle Exemple de valeur
segment texte labels : nom de la part Entreprises
part nombre column : taille de la part 35

Paramètres

Paramètre Défaut Description
column obligatoire Colonne des valeurs (tailles des parts).
labels None Colonne utilisée comme étiquettes. Utilise l’index par défaut.
autopct '%1.1f%%' Format de chaîne de style printf pour les pourcentages.
startangle 90 Angle en degrés pour le premier secteur.
explode None Décalage fractionnaire pour extraire chaque secteur (0 = pas de décalage).

Exemple

df = pd.DataFrame({
    'segment': ['Résidentiel','Professionnel','Industrie','Administration'],
    'part':    [42, 28, 18, 12],
})

(Chart(df)
    .pie('part', labels='segment', autopct='%1.1f%%',
         explode=[0.05, 0, 0, 0])
    .title('Parts de marché 2024')
    .tight_layout()
    .show())

donut — Anneau

Anneau : un camembert évidé, avec un texte au centre ; avec group, deux anneaux imbriqués (groupes à l’intérieur, éléments à l’extérieur).

Quand l’utiliser. Répartition d’un total avec un chiffre clé au centre, ou composition hiérarchique à deux niveaux (famille de cultures → culture).

Données attendues : un DataFrame, une ligne par élément.

Colonne (exemple) Type Rôle Exemple de valeur
culture texte labels : nom de l’élément Mil
surface nombre values : taille 420
famille texte group (optionnel) : anneau intérieur Céréales

Paramètres

Paramètre Défaut Description
values obligatoire Colonne des valeurs (taille de chaque secteur).
labels None Colonne des étiquettes (noms affichés).
group None Colonne de regroupement : une couleur (et une entrée de légende) par groupe.
hole 0.55 Taille du trou central, en fraction du rayon (0 = camembert).
center_text None Texte écrit au centre de l’anneau (total, titre…).
show_values True Écrit les valeurs sur le graphique.

Exemple

Un camembert évidé, avec un texte central ; avec group, deux anneaux imbriqués (groupes à l’intérieur, éléments à l’extérieur).

(Chart(cultures, figsize=(8, 7))
    .donut('surface', labels='culture', group='famille', center_text='1 865 ha')
    .title('Assolement')
    .tight_layout()
    .show())

treemap — Carte arborescente

Carte arborescente : des rectangles juxtaposés d’aire proportionnelle à la valeur (paquet squarify).

Quand l’utiliser. Comparer les parts de nombreux éléments d’un total (budgets, surfaces, ventes) dans un espace compact.

Données attendues : un DataFrame, une ligne par élément.

Colonne (exemple) Type Rôle Exemple de valeur
departement texte labels : nom du rectangle R&D
budget nombre values : aire du rectangle 420

Paramètres

Paramètre Défaut Description
values obligatoire Colonne avec des tailles numériques positives (détermine l’aire du rectangle).
labels None Colonne pour les étiquettes textuelles à l’intérieur de chaque rectangle.
alpha 0.9 Opacité du remplissage.
show_values True Écrit les valeurs sur le graphique.
value_format '{:,.0f}' Format des valeurs affichées ({:,.0f}, {:.1%}…).

Exemple

df = pd.DataFrame({
    'departement': ['R&D','Ventes','Marketing','Ops','Finance','IT','RH'],
    'budget':      [450, 380, 210, 280, 150, 200, 120],
})

(Chart(df)
    .treemap('budget', labels='departement', alpha=0.85)
    .title('Répartition budgétaire par département (k€)')
    .tight_layout()
    .show())

circle_packing — Cercles imbriqués

Cercles imbriqués (circlify) : un cercle par élément, d’aire proportionnelle à la valeur, regroupés dans le cercle de leur groupe.

Quand l’utiliser. Composition hiérarchique (familles → cultures, régions → communes) quand l’aspect visuel compte plus que la lecture précise des valeurs.

Données attendues : un DataFrame, une ligne par élément (feuille de la hiérarchie).

Colonne (exemple) Type Rôle Exemple de valeur
culture texte labels : nom du cercle Arachide
surface nombre values : aire du cercle 380
famille texte group (optionnel) : cercle englobant Légumineuses

Paramètres

Paramètre Défaut Description
values obligatoire Colonne des valeurs (aire de chaque cercle).
labels None Colonne des étiquettes (défaut : l’index).
group None Colonne (ou liste de colonnes pour plusieurs niveaux) des groupes englobants.
show_labels True Écrit le nom des éléments dans les cercles.
show_values False Ajoute la valeur sous l’étiquette.
alpha 0.85 Opacité, de 0 (transparent) à 1 (opaque).
min_label_radius 0.05 Rayon minimal (en fraction du cercle principal) pour écrire une étiquette.

Exemple

Un cercle par ligne, d’aire proportionnelle à la valeur (calcul par circlify). Avec group, les cercles sont regroupés dans le cercle de leur groupe ; une liste de colonnes donne plusieurs niveaux d’imbrication (group=['cycle', 'famille']).

cultures = pd.DataFrame({
    'famille': ['Céréales'] * 4 + ['Légumineuses'] * 3 + ['Tubercules'] * 3 + ['Maraîchage'] * 3,
    'culture': ['Riz', 'Maïs', 'Mil', 'Sorgho', 'Niébé', 'Arachide', 'Soja',
                'Manioc', 'Igname', 'Patate douce', 'Tomate', 'Oignon', 'Gombo'],
    'surface': [420, 310, 180, 150, 140, 260, 60, 230, 120, 70, 45, 55, 25],
})

(Chart(cultures, figsize=(8, 8))
    .circle_packing('surface', labels='culture', group='famille', show_values=True)
    .title('Surfaces cultivées (ha)')
    .tight_layout()
    .show())

waterfall — Cascade financière

Cascade : chaque barre part du total cumulé précédent et monte (valeur positive) ou descend (valeur négative).

Quand l’utiliser. Expliquer le passage d’une valeur de départ à une valeur finale : compte de résultat, bilan d’une exploitation, décomposition d’un écart.

Données attendues : un DataFrame, une ligne par poste, dans l’ordre du cumul.

Colonne (exemple) Type Rôle Exemple de valeur
poste texte x : libellé de l’étape Engrais
delta nombre y : variation (+ ou −) -220

Paramètres

Paramètre Défaut Description
x obligatoire Colonne avec les étiquettes de catégories ou de périodes.
y obligatoire Colonne avec les valeurs incrémentielles (positives ou négatives).
positive_color None Couleur des barres pour les incréments positifs.
negative_color None Couleur des barres pour les incréments négatifs.

Exemple

df = pd.DataFrame({
    'poste': ['CA','Coût prod.','Marge brute','Loyers','Salaires','Marketing','Résultat'],
    'delta': [500, -200, 300, -60, -140, -40, 60],
})

(Chart(df)
    .waterfall('poste', 'delta',
               positive_color='#2a9d8f', negative_color='#e76f51')
    .title('Compte de résultat Q4 (k€)')
    .labels(ylabel='k€')
    .rotate_labels(x_rotation=25)
    .grid(alpha=0.25)
    .tight_layout()
    .show())

ternary — Diagramme ternaire

Diagramme ternaire : chaque point est une composition en trois parts de somme constante, placée dans un triangle.

Quand l’utiliser. Compositions à trois composantes : texture du sol (sable / limon / argile), parts de budget, composition chimique.

Données attendues : un DataFrame, une ligne par échantillon.

Colonne (exemple) Type Rôle Exemple de valeur
sable nombre a : sommet bas gauche 45
limon nombre b : sommet bas droit 35
argile nombre c : sommet haut 20
zone texte group (optionnel) Plateau

Paramètres

Paramètre Défaut Description
a obligatoire Colonne de la première composante (sommet en bas à gauche).
b obligatoire Colonne de la deuxième composante (sommet en bas à droite).
c obligatoire Colonne de la troisième composante (sommet en haut).
group None Colonne de regroupement : une couleur (et une entrée de légende) par groupe.
grid_step 0.1 Pas de la grille (en fraction) ; 0.1 = lignes tous les 10 %.
alpha 0.85 Opacité, de 0 (transparent) à 1 (opaque).
size 40 Taille des points.

Exemple

Pour des compositions en trois parts (pourcentages ou fractions), comme la texture du sol. Sommets : premier argument en bas à gauche, deuxième en bas à droite, troisième en haut.

rng = np.random.default_rng(11)
sols = pd.DataFrame({'zone': rng.choice(['bas-fond', 'plateau'], 40)})
sols['sable'] = np.where(sols['zone'] == 'plateau', rng.uniform(55, 85, 40), rng.uniform(10, 45, 40))
sols['argile'] = rng.uniform(5, 100 - sols['sable'] - 5)
sols['limon'] = 100 - sols['sable'] - sols['argile']

(Chart(sols, figsize=(7, 6.5))
    .ternary('sable', 'limon', 'argile', group='zone')
    .title('Texture des sols (%)')
    .tight_layout()
    .show())

sankey — Diagramme de Sankey

Diagramme de Sankey (matplotlib) : un flux principal qui se divise en entrées et sorties de largeur proportionnelle à leur valeur.

Quand l’utiliser. Bilans de flux simples : répartition d’une récolte (vente, stock, pertes), bilan énergétique ou financier.

Données attendues : un DataFrame, une ligne par flux ; entrées positives, sorties négatives (la somme doit être nulle).

Colonne (exemple) Type Rôle Exemple de valeur
flux nombre flows : + entrée, − sortie -60
etiquette texte labels : nom du flux Vente
direction entier (−1, 0, 1) orientations (optionnel) : 1 = vers le haut, −1 = vers le bas, 0 = horizontal 0

Paramètres

Paramètre Défaut Description
flows obligatoire Colonne avec les amplitudes de flux (positif = entrée, négatif = sortie).
labels obligatoire Colonne avec l’étiquette de chaque segment de flux.
orientations None Colonne avec les orientations entières : 0 = droite, 1 = haut, –1 = bas.
unit '' Chaîne d’unité ajoutée à chaque étiquette numérique (ex. ’ MW’).
scale 0.01 Facteur d’échelle global ; valeur plus petite = flèches plus larges.

Exemple

df = pd.DataFrame({
    'flux':       [200, -80,  -50, -70,   80,  -30, -50],
    'etiquette':  ['Revenus','Coût matières','Loyers','Salaires',
                   'Marge brute','Taxes','Bénéfice net'],
    'direction':  [0, 1, 1, -1, 0, 1, -1],
})

(Chart(df)
    .sankey('flux', 'etiquette', orientations='direction', unit=' k€', scale=0.005)
    .title('Flux financiers (k€)')
    .tight_layout()
    .show())

radial_bar — Barres radiales

Barres radiales : un arc concentrique par élément, dont la longueur représente la valeur rapportée à un maximum (un tour complet).

Quand l’utiliser. Taux d’avancement ou d’atteinte d’objectifs de plusieurs indicateurs (en %), présentés de façon compacte.

Données attendues : un DataFrame, une ligne par indicateur.

Colonne (exemple) Type Rôle Exemple de valeur
activite texte labels : nom de l’arc Semis
pct nombre values : valeur (sur max_value) 85

Paramètres

Paramètre Défaut Description
values obligatoire Colonne des valeurs.
labels None Colonne des étiquettes (noms affichés).
max_value 100 Valeur correspondant à un tour complet (100 pour des pourcentages).
width 0.12 Épaisseur de chaque anneau.
gap 0.04 Espace entre les anneaux.
show_values True Écrit les valeurs sur le graphique.

Exemple

Un arc concentrique par indicateur, sa longueur rapportée à un tour complet.

(Chart(avancement, figsize=(6, 6.5))
    .radial_bar('pct', labels='activite')
    .title('Avancement du projet')
    .tight_layout()
    .show())

progress_bar — Barre de progression

Barres de progression : une barre pleine sur un rail clair, une par indicateur.

Quand l’utiliser. Suivi d’avancement (tâches, budget consommé, objectifs) dans un tableau de bord ou un rapport.

Données attendues : un DataFrame, une ligne par indicateur (ou un seul nombre).

Colonne (exemple) Type Rôle Exemple de valeur
activite texte labels : nom de la barre Récolte
pct nombre value : avancement 40

Paramètres

Paramètre Défaut Description
value obligatoire Une colonne (une barre par ligne) ou un nombre (une seule barre).
total 100 Valeur correspondant à une barre pleine.
labels None Colonne des étiquettes (noms affichés).
color None Couleur unique (nom, hexadécimal). None : couleur du thème.
height 0.5 Épaisseur des barres.

Exemple

Une barre pleine sur un rail clair : un nombre, ou une colonne (une barre par ligne).

(Chart(avancement, figsize=(8, 2.8))
    .progress_bar('pct', labels='activite')
    .title('Objectifs atteints')
    .tight_layout()
    .show())
