Champs

Une grandeur répartie dans l’espace : grilles régulières ou prélèvements dispersés.

Tous les exemples utilisent le thème editorial ; chaque graphique suit le thème actif (set_theme(...)). Retour à la galerie.

contour — Courbes de niveau

Courbes de niveau d’une grandeur z dans le plan (x, y) : sur une grille régulière, ou sur des points dispersés par triangulation.

Quand l’utiliser. Cartographier une variable mesurée sur une parcelle (pH, humidité), une surface de réponse (rendement selon azote × eau), un relief.

Données attendues : un DataFrame, une ligne par point (x, y) ; grille régulière ou points dispersés.

Colonne (exemple) Type Rôle Exemple de valeur
x nombre x : abscisse du point 35.0
y nombre y : ordonnée du point 12.5
ph nombre z : valeur mesurée 6.4

Paramètres

Paramètre Défaut Description
x obligatoire Colonne de l’axe horizontal.
y obligatoire Colonne de l’axe vertical.
z obligatoire Colonne de la troisième dimension (hauteur, valeur).
filled True Aplats de couleur entre les courbes (sinon seulement les lignes).
levels 10 Nombre de niveaux (ou liste des seuils) des courbes de niveau.
cmap None Palette de couleurs continue (nom matplotlib). None : celle du thème.
show_points False Affiche aussi les points de mesure.
show_mesh False Dessine la triangulation des points dispersés.
labels True Écrit la valeur sur les courbes de niveau.
colorbar True Affiche l’échelle de couleurs.

Exemple

Sur une grille régulière (contourf) ou, comme ici, sur des prélèvements dispersés : la surface est alors interpolée par triangulation (tricontourf). show_points et show_mesh montrent les points et le maillage.

(Chart(champ, figsize=(9, 5.5))
    .contour('x', 'y', 'ph', show_points=True, show_mesh=True)
    .title('Carte du pH de la parcelle')
    .labels('x (m)', 'y (m)')
    .tight_layout()
    .show())

mesh — Grille colorée

Cellules colorées selon z : un rectangle par case d’une grille régulière, ou un triangle entre points dispersés.

Quand l’utiliser. Montrer une grandeur sur une grille sans lissage (résultats de simulation, rendements par placette, images).

Données attendues : un DataFrame, une ligne par point (x, y).

Colonne (exemple) Type Rôle Exemple de valeur
azote nombre x 60
eau nombre y 400
rendement nombre z : couleur de la cellule 4.8

Paramètres

Paramètre Défaut Description
x obligatoire Colonne de l’axe horizontal.
y obligatoire Colonne de l’axe vertical.
z obligatoire Colonne de la troisième dimension (hauteur, valeur).
cmap None Palette de couleurs continue (nom matplotlib). None : celle du thème.
colorbar True Affiche l’échelle de couleurs.
show_points False Affiche aussi les points de mesure.

Exemple

Une cellule colorée par point d’une grille régulière (pcolormesh), ou des triangles colorés sur des points dispersés (tripcolor).

(Chart(reponse, figsize=(9, 5))
    .mesh('azote', 'eau', 'rendement')
    .title('Rendement (t/ha)')
    .labels('Azote (kg/ha)', 'Irrigation (mm)')
    .tight_layout()
    .show())

vector_field — Champ de vecteurs

Champ de vecteurs : en chaque point une flèche (direction et intensité), des barbules de vent ou des lignes de courant.

Quand l’utiliser. Vent, courants, écoulements, gradients : tout ce qui a une direction et une intensité en chaque lieu.

Données attendues : un DataFrame, une ligne par point de la grille.

Colonne (exemple) Type Rôle Exemple de valeur
lon nombre x : position -16.5
lat nombre y : position 14.2
u nombre u : composante est-ouest 3.2
v nombre v : composante nord-sud -1.1

Paramètres

Paramètre Défaut Description
x obligatoire Colonne de l’axe horizontal.
y obligatoire Colonne de l’axe vertical.
u obligatoire Colonne de la composante horizontale (vers l’est / la droite).
v obligatoire Colonne de la composante verticale (vers le nord / le haut).
kind 'quiver' ‘quiver’ (flèches), ‘barbs’ (barbules de vent) ou ‘stream’ (lignes de courant, grille régulière).
cmap None Palette de couleurs continue (nom matplotlib). None : celle du thème.
density 1.2 Densité des lignes de courant (kind='stream').
colorbar True Affiche l’échelle de couleurs.

Exemple

Vent, écoulement, gradient : flèches (quiver), barbules de vent (barbs) ou lignes de courant (stream, grille régulière), colorées par l’intensité.

(Chart(vent, figsize=(9, 6))
    .vector_field('lon', 'lat', 'u', 'v', kind='stream')
    .title('Vent autour d\'une dépression')
    .tight_layout()
    .show())
(Chart(vent, figsize=(9, 6))
    .vector_field('lon', 'lat', 'u', 'v', kind='quiver')
    .title('Vent (flèches)')
    .tight_layout()
    .show())
