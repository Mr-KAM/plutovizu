Graphes & réseaux

Réseaux, mouvements, optimisation et recherche opérationnelle : plus court chemin, arbre couvrant, flot maximal, chemin critique, tournées.

Tous les exemples utilisent le thème editorial. Retour à la galerie.

Note

Un réseau se décrit par une liste d’arêtes : un DataFrame avec une ligne par lien (colonne source, colonne cible, et souvent un poids : distance, coût, capacité, effectif). Les calculs reposent sur scipy.sparse.csgraph et sont aussi disponibles sans graphique : from plutovizu import shortest_path, spanning_tree, max_flow, critical_path, tsp. Les données de cette page sont fictives.

Réseaux et mouvements

network — Graphe de réseau

Graphe de réseau tracé à partir d’une liste d’arêtes : nœuds dimensionnés selon leur nombre de liens (degré), liens d’épaisseur proportionnelle au poids, flèches si le réseau est orienté.

Quand l’utiliser. Visualiser des relations : échanges entre acteurs, filières, réseaux sociaux, pistes entre villages, interactions entre espèces. Repérer les nœuds centraux et les sous-groupes.

Données attendues : un DataFrame, une ligne par lien (arête) ; les nœuds sont déduits des deux premières colonnes.

Colonne (exemple) Type Rôle Exemple de valeur
de texte source : nœud de départ Coop A
vers texte target : nœud d’arrivée Coop B
tonnes nombre weight (optionnel) : intensité du lien (> 0) 12

Paramètres

Paramètre Défaut Description
source obligatoire Colonne du nœud de départ de chaque lien.
target obligatoire Colonne du nœud d’arrivée de chaque lien.
weight None Colonne du poids des liens (épaisseur) ; valeurs strictement positives.
directed False Réseau orienté (flèches de la source vers la cible).
layout 'spring' Placement des nœuds : ‘spring’ (forces), ‘circular’, ou un dictionnaire {nœud: (x, y)} (coordonnées réelles).
node_size 'degree' ‘degree’ (taille selon le nombre de liens) ou une taille fixe (points²).
labels True Écrit le nom des nœuds.
edge_labels False Écrit le poids sur chaque lien.
max_width 6.0 Épaisseur du lien le plus lourd.

Résultats calculés : chart.graph : nœuds, positions et degré de chaque nœud.

Exemple

chart = (Chart(echanges, figsize=(9, 6.5))
    .network('de', 'vers', weight='tonnes', directed=True, edge_labels=True)
    .title('Échanges entre coopératives (t)')
    .tight_layout())
chart.show()
chart.graph['degree'].sort_values(ascending=False)
Coop A    4
Coop B    4
Coop C    4
Coop D    3
Coop E    3
Coop F    2
Name: degre, dtype: int64

Avec des coordonnées réelles, layout reçoit un dictionnaire {nœud: (x, y)} :

positions = {'Dépôt': (0, 0), 'Keur Massar': (3, 2), 'Ndiaye': (4, -1), 'Sangalkam': (7, 3),
             'Bayakh': (8, 0), 'Kayar': (11, 3), 'Pout': (7, -4), 'Tivaouane': (12, -2)}
(Chart(pistes, figsize=(9, 5))
    .network('de', 'vers', weight='km', layout=positions, edge_labels=True)
    .title('Pistes rurales (km)')
    .tight_layout()
    .show())

arc_diagram — Diagramme en arcs

Diagramme en arcs : les nœuds alignés sur une ligne, un arc par lien ; les mouvements vers la droite passent au-dessus, ceux vers la gauche en dessous.

Quand l’utiliser. Lire le sens et l’intensité de mouvements entre lieux ordonnés (zones le long d’un gradient, villes d’un axe) : transhumance, migrations, transferts.

Données attendues : un DataFrame, une ligne par mouvement (départ → arrivée).

Colonne (exemple) Type Rôle Exemple de valeur
depart texte source : lieu de départ Ferlo
arrivee texte target : lieu d’arrivée Saloum
tetes nombre weight (optionnel) : effectif déplacé 420

Paramètres

Paramètre Défaut Description
source obligatoire Colonne du lieu de départ.
target obligatoire Colonne du lieu d’arrivée.
weight None Colonne de l’intensité du mouvement (épaisseur de l’arc).
order None Liste des nœuds dans l’ordre d’affichage (ex. du nord au sud) ; None = ordre d’apparition.
max_width 8.0 Épaisseur de l’arc le plus lourd.
labels True Écrit le nom des nœuds.

Exemple

(Chart(transferts, figsize=(10, 5.5))
    .arc_diagram('depart', 'arrivee', weight='tetes',
                 order=['Fleuve', 'Ferlo', 'Niayes', 'Saloum', 'Casamance'])
    .title('Mouvements de troupeaux')
    .tight_layout()
    .show())

Optimisation et recherche opérationnelle

shortest_path — Plus court chemin

Plus court chemin entre deux nœuds (algorithme de Dijkstra), mis en évidence sur le réseau ; les autres liens sont estompés.

Quand l’utiliser. Recherche d’itinéraire : trajet le plus court ou le moins coûteux entre deux lieux (pistes, réseau routier, logistique), chemin de moindre résistance.

Données attendues : un DataFrame, une ligne par lien ; le poids est une distance, un temps ou un coût (> 0).

Colonne (exemple) Type Rôle Exemple de valeur
de texte source Dépôt
vers texte target Ndiaye
km nombre weight (optionnel) : longueur du lien 18

Paramètres

Paramètre Défaut Description
source obligatoire Colonne d’une extrémité de chaque lien.
target obligatoire Colonne de l’autre extrémité.
start obligatoire Nœud de départ.
end obligatoire Nœud d’arrivée.
weight None Colonne des longueurs (distance, temps, coût) ; None = chaque lien compte 1.
directed False Liens à sens unique (de source vers target).
layout 'spring' Placement des nœuds : ‘spring’, ‘circular’ ou {nœud: (x, y)}.
edge_labels True Écrit la longueur sur chaque lien.
color None Couleur du chemin ; None = couleur d’accent du thème.

Résultats calculés : chart.path (liste des nœuds), chart.path_length (longueur totale).

Exemple

chart = (Chart(pistes, figsize=(9, 6.5))
    .shortest_path('de', 'vers', 'Dépôt', 'Tivaouane', weight='km')
    .title('Plus court chemin (Dijkstra)')
    .tight_layout())
chart.show()
print(' → '.join(chart.path), '|', chart.path_length, 'km')
Dépôt → Ndiaye → Bayakh → Tivaouane | 55.0 km

spanning_tree — Arbre couvrant minimal

Arbre couvrant minimal : l’ensemble de liens le moins coûteux qui relie tous les nœuds, en gras ; les liens non retenus en pointillés.

Quand l’utiliser. Concevoir un réseau au moindre coût : électrification de villages, canaux d’irrigation, adduction d’eau, fibre, pistes à aménager.

Données attendues : un DataFrame, une ligne par lien possible, avec son coût (> 0).

Colonne (exemple) Type Rôle Exemple de valeur
de texte source Bayakh
vers texte target Kayar
km nombre weight : coût du lien 14

Paramètres

Paramètre Défaut Description
source obligatoire Colonne d’une extrémité de chaque lien.
target obligatoire Colonne de l’autre extrémité.
weight None Colonne du coût de chaque lien ; None = coûts égaux.
layout 'spring' Placement des nœuds : ‘spring’, ‘circular’ ou {nœud: (x, y)}.
edge_labels True Écrit le coût sur chaque lien.
color None Couleur de l’arbre ; None = couleur d’accent du thème.

Résultats calculés : chart.tree (liens retenus), chart.tree_weight (coût total).

Exemple

chart = (Chart(pistes, figsize=(9, 6.5))
    .spanning_tree('de', 'vers', weight='km')
    .title('Réseau électrique minimal')
    .tight_layout())
chart.show()

max_flow — Flot maximal

Flot maximal d’une source vers un puits dans un réseau orienté à capacités : épaisseur des flèches selon le flux, étiquettes flux/capacité, liens saturés (goulots) en couleur d’accent.

Quand l’utiliser. Dimensionner ou diagnostiquer un réseau : débit maximal d’adduction d’eau, capacité d’une chaîne d’approvisionnement, trafic ; les liens saturés sont à renforcer en priorité.

Données attendues : un DataFrame, une ligne par lien orienté, avec sa capacité (> 0).

Colonne (exemple) Type Rôle Exemple de valeur
de texte source : origine du lien Forage
vers texte target : destination du lien Château A
capacite nombre capacity : débit maximal du lien 60

Paramètres

Paramètre Défaut Description
source obligatoire Colonne de l’origine de chaque lien orienté.
target obligatoire Colonne de la destination de chaque lien.
capacity obligatoire Colonne des capacités (décimales arrondies au millième).
start obligatoire Nœud source (d’où part le flux).
end obligatoire Nœud puits (où arrive le flux).
layout 'spring' Placement des nœuds : ‘spring’, ‘circular’ ou {nœud: (x, y)}.
max_width 7.0 Épaisseur du lien le plus chargé.
color None Couleur des liens saturés ; None = couleur d’accent du thème.

Résultats calculés : chart.flow_value (flot maximal), chart.flow (flux sur chaque lien).

Exemple

chart = (Chart(adduction, figsize=(9, 6.5))
    .max_flow('de', 'vers', 'capacite', 'Forage', 'Marché')
    .title("Réseau d'adduction d'eau")
    .tight_layout())
chart.show()

critical_path — Chemin critique (PERT / CPM)

Chemin critique (méthode CPM / PERT) en diagramme de Gantt : chaque tâche à sa date au plus tôt, marge totale hachurée, tâches critiques (marge nulle) en couleur d’accent, flèches de dépendance.

Quand l’utiliser. Planifier un projet (aménagement, campagne agricole, chantier) : durée minimale, tâches qui ne peuvent prendre aucun retard, marges disponibles pour les autres.

Données attendues : un DataFrame, une ligne par tâche, avec sa durée et la liste de ses prédécesseurs.

Colonne (exemple) Type Rôle Exemple de valeur
tache texte task : nom de la tâche Canaux
duree nombre duration : durée (jours, semaines…) 8
avant texte ou liste predecessors : tâches à finir avant, séparées par des virgules (’’ si aucune) Défrichage, Financement

Paramètres

Paramètre Défaut Description
task obligatoire Colonne des noms de tâches (uniques).
duration obligatoire Colonne des durées.
predecessors obligatoire Colonne des prédécesseurs (texte ‘A, B’, liste, ou vide).
show_float True Affiche la marge totale de chaque tâche (hachures).
color None Couleur des tâches critiques ; None = couleur d’accent du thème.

Résultats calculés : chart.schedule (dates au plus tôt / au plus tard, marges, tâches critiques), chart.project_duration.

Exemple

chart = (Chart(projet, figsize=(10, 5.5))
    .critical_path('tache', 'duree', 'avant')
    .title('Chemin critique du projet')
    .tight_layout())
chart.show()
print('Durée du projet :', chart.project_duration, 'semaines')
chart.schedule.drop(columns='predecesseurs')

tsp_route — Tournée optimale (voyageur de commerce)

Tournée du voyageur de commerce : le circuit le plus court passant une fois par chaque point (heuristique du plus proche voisin améliorée par 2-opt), numéros de passage sur les points.

Quand l’utiliser. Optimiser une tournée : collecte de lait, livraison d’intrants, visites de parcelles ou de pièges. L’ordre obtenu peut être tracé sur un fond de carte avec route_map.

Données attendues : un DataFrame, une ligne par point à visiter (coordonnées planes : km, mètres ; en degrés, la distance est approchée).

Colonne (exemple) Type Rôle Exemple de valeur
ferme texte labels (optionnel) : nom du point F3
x nombre x : abscisse 12
y nombre y : ordonnée -2

Paramètres

Paramètre Défaut Description
x obligatoire Colonne des abscisses.
y obligatoire Colonne des ordonnées.
labels None Colonne des noms des points.
start None Point de départ (nom si labels, sinon numéro de ligne) ; None = premier point.
closed True Revient au point de départ (circuit fermé).
color None Couleur de la tournée ; None = thème.

Résultats calculés : chart.tour (ordre de visite), chart.tour_length, chart.tour_table (données triées + colonne ordre).

Exemple

chart = (Chart(collecte, figsize=(9, 6.5))
    .tsp_route('x', 'y', labels='ferme', start='Laiterie')
    .labels('x (km)', 'y (km)')
    .title('Tournée de collecte')
    .tight_layout())
chart.show()
print(' → '.join(chart.tour), '| longueur :', round(chart.tour_length, 1), 'km')
Laiterie → F6 → F5 → F4 → F3 → F2 → F9 → F1 → F8 → F7 | longueur : 61.8 km
