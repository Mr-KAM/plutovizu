Palettes de couleurs

Palettes seaborn intégrées

df = pd.DataFrame({
    'x': range(10),
    'A': np.random.randn(10).cumsum(),
    'B': np.random.randn(10).cumsum(),
    'C': np.random.randn(10).cumsum(),
    'D': np.random.randn(10).cumsum(),
})

(Chart(df)
    .set_colors('deep')
    .line('x', ['A', 'B', 'C', 'D'], marker='o')
    .title("Palette seaborn 'deep'")
    .set_legend()
    .grid(alpha=0.3)
    .tight_layout()
    .show())

Palettes seaborn qualitatives disponibles :

Palette Usage recommandé
deep Catégories distinctes (défaut seaborn)
pastel Fond clair, couleurs douces
bright Forte visibilité
dark Fond sombre ou impression
colorblind Accessible aux daltoniens
Set1, Set2, Set3 Catégories qualitatives
tab10, tab20 Nombreuses catégories

Palette personnalisée

df = pd.DataFrame({
    'categorie': ['A', 'B', 'C', 'D', 'E'],
    'valeur':    [80, 65, 90, 45, 72],
})

(Chart(df)
    .create_custom_palette('brand', ['#003049','#d62828','#f77f00','#fcbf49','#eae2b7'])
    .set_colors('brand')
    .bar('categorie', 'valeur')
    .title("Palette personnalisée 'brand'")
    .labels(xlabel='Catégorie', ylabel='Valeur')
    .grid(alpha=0.3)
    .tight_layout()
    .show())
Custom palette 'brand' created with 5 colors
# Créer et réutiliser une palette personnalisée
chart.create_custom_palette(
    'brand',
    ['#003049', '#d62828', '#f77f00', '#fcbf49', '#eae2b7']
)
# Appliquer dans le même chaînage
chart.set_colors('brand')

Annotations

df = pd.DataFrame({
    'mois':   list(range(1, 13)),
    'ventes': [12, 15, 18, 22, 28, 35, 40, 38, 30, 25, 20, 16],
})

(Chart(df)
    .line('mois', 'ventes', marker='o', linewidth=2)
    .add_annotation(7, 40, 'Pic estival', fontsize=11,
                    color='red', arrow=True)
    .title('Ventes mensuelles avec annotation')
    .labels(xlabel='Mois', ylabel='k€')
    .grid(alpha=0.3)
    .tight_layout()
    .show())
chart.add_annotation(

Grille, légende, limites

np.random.seed(0)
df = pd.DataFrame({
    'x': range(20),
    'A': np.random.randn(20).cumsum(),
    'B': np.random.randn(20).cumsum(),
})

(Chart(df)
    .line('x', ['A', 'B'])
    .grid(show=True, alpha=0.4, linestyle='--', linewidth=0.8)
    .set_legend(show=True, location='upper left', fontsize=11, frameon=True)
    .set_limits(xlim=(0, 19), ylim=(-8, 8))
    .title("Grille personnalisée + limites d'axes")
    .tight_layout()
    .show())

Export

# Enregistrer en PNG haute résolution (retourne self — chaînable)
chart.save('sortie.png', dpi=300)

# Enregistrer en PDF vectoriel
chart.save('rapport.pdf', format='pdf')

# Enregistrer en SVG
chart.save('figure.svg', format='svg', bbox_inches='tight')

# Accéder aux objets matplotlib bruts pour personnalisation avancée
fig, ax = chart.get_figure()
ax.axvspan(3, 5, alpha=0.1, color='red')   # zone colorée
fig.savefig('custom.png', dpi=300)
